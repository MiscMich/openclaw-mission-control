# Provenance

This repository is a sanitized public edition of a privately developed workflow dashboard. The public history starts with one root commit to keep personal agent rosters, workspace paths, deployment configuration, and operational data out of GitHub history.

The interface, workflow models, tests, security boundaries, and retained integration code are real source code. This public edition intentionally runs only as a deterministic local demo; it is not the production deployment and cannot be switched into live mode with environment variables.

Upstream attribution and license obligations are documented in `NOTICE.md` and `LICENSES/Apache-2.0.txt`.
